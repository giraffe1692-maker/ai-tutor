
# 가우스 법칙 적응형 문제풀이 앱 v2

## 주요 기능

- 1수준: 부도체 구 외부 전기장
- 2수준: 부도체 구 내부와 외부 전기장
- 3수준: 두꺼운 부도체 구껍질 전기장
- 학생이 선택한 오답에 따라 오류 유형 자동 진단
- 즉각적인 오류 설명과 단계별 힌트 제공
- 각 수준 종료 시 누적 오류 빈도 분석
- 다음 수준으로 넘어가기 전 개인화 피드백 제공
- 전체 학습 종료 시 오류 유형 종합
- CSV 학습 로그 저장 및 다운로드

## 설치

Python 3.10 이상 권장

```bash
pip install -r requirements.txt
```

## 실행

```bash
streamlit run app.py
```

## 저장되는 자료

- 학습자 ID
- 수준
- 풀이 단계
- 선택한 답
- 정오
- 오류 코드
- 힌트 사용 횟수
- 시도 횟수
- 응답 시각


## v3 수정 사항

- 마지막 결과 화면에서 전체 오류 유형 요약과 상세 학습 로그가 빈칸으로 표시되던 문제 수정
- 학습 응답을 CSV뿐 아니라 Streamlit 세션에도 동시에 저장
- 종료 화면에서는 현재 세션 기록을 우선 사용
- CSV의 `correct` 값이 문자열로 읽히는 경우에도 정오 판정 가능
- 학습자 ID의 공백과 자료형 차이를 정규화하여 필터링


## v4 수식 표시 수정

- `st.radio` 안에서 LaTeX가 문자 그대로 표시되던 문제 수정
- 선택지 수식은 `st.latex()`로 별도 렌더링
- 학생은 A–D 기호로 선택
- 선택한 수식을 정답 확인 전에 다시 표시
- 문제와 힌트의 `\( ... \)` 표기를 Streamlit 인라인 수식으로 변환
- 내부·외부 및 세 영역 전기장 식을 `cases` 형식으로 줄바꿈하여 표시


## v5 온라인 다중 사용자 버전

- Streamlit Community Cloud 배포 가능
- Supabase 중앙 데이터베이스 연동
- 학생별 고유 세션 UUID 생성
- 여러 학생의 동시 접속 및 동시 저장 지원
- 학생에게는 자신의 세션 결과만 표시
- 비밀번호로 보호된 연구자 관리자 화면
- 전체 오류 통계, 학생별 현황 및 CSV 다운로드
- 데이터베이스 미연결 시 로컬 CSV 백업
- 자세한 배포 방법은 `ONLINE_DEPLOYMENT.md` 참조


## v6 AI 튜터 기능

- 각 문제풀이 단계 하단에 AI 대화창 추가
- 현재 수준, 현재 단계, 선택 답, 오류 유형을 문맥으로 전달
- 정답을 바로 주지 않는 소크라테스식 튜터 지침 적용
- 단계별 대화 기록을 학생 세션별로 분리
- 빠른 질문 메뉴와 자유 질문 입력 제공
- 현재 단계 대화 초기화 기능
- 학생 세션당 최대 20회 호출 제한
- OpenAI API 키는 Streamlit Secrets에서만 관리


## v7 AI 대화 로그
학생 질문, AI 응답, 호출 실패를 Supabase ai_chat_logs에 저장하며 관리자·학생 화면에서 CSV로 내려받을 수 있습니다.
